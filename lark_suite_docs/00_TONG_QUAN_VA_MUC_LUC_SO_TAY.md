## 💡 HƯỚNG DẪN IMPORT VÀO LARK WIKI / LARK DOCS
1. **Cách 1 - Tạo trang Lark Wiki**: Trong không gian Wiki của Rikkei Education, chọn **New Page** ➔ **Import** ➔ Chọn file `.md` trong thư mục `lark_suite_docs`.
2. **Cách 2 - Copy trực tiếp**: Mở từng file Markdown, copy toàn bộ nội dung và dán trực tiếp vào trang Lark Docx. Hệ thống sẽ tự động nhận diện tiêu đề, bảng biểu, danh sách và callout đẹp mắt!
